# Калькулятор

Минималистичный калькулятор с поддержкой базовых арифметических операций (+, -, \*, /) и тригонометрических функций (sin, cos, tan). Написан на чистом HTML, CSS, JavaScript и стандартной библиотеке Python 3 без использования сторонних фреймворков и сборщиков.

## Архитектура
* **Frontend:** HTML5, CSS3, Vanilla JS
* **Backend:** Python 3

## Структура проекта
```text
.
├── index.html
├── style.css 
├── script.js
└── server.py

```

## Требования

* Установленный **Python 3.6+**
* Любой современный браузер

## Локальный запуск

1. **Клонируйте репозиторий** или перейдите в папку с проектом:
```bash
cd calculator
```


2. **Запустите Python-сервер:**
```bash
python main.py
```


3. **Откройте калькулятор в браузере:**
Перейдите по адресу [http://localhost:8000](http://localhost:8000).

> **Важно:** Открывайте проект именно через адрес `http://localhost:8000` (через запущенный Python-сервер), а не через прямой клик по `index.html`, иначе API-запросы к бэкенду не будут работать.
